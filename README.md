# ⚡ EV Global Hub (글로벌 48종 순수전기차 BEV 판매량·4개국 가격·성능 비교 대시보드)

전 세계에서 가장 많이 팔리는 베스트셀러 순수전기차(BEV)들과 최신 출시 전기차(2024~2026)를 한눈에 비교할 수 있는 정적 웹 애플리케이션입니다. 하이브리드(HEV/PHEV/EREV)를 완전히 배제한 **100% 순수 배터리 전기차(Pure BEV)**만을 다루며, **GitHub Pages** (`https://electric.yocto.co.kr/`)에 호스팅되어 있습니다.

## ✨ 주요 특징 및 아키텍처

1. **글로벌 5대 권역 & 48개 핵심 순수전기차(BEV) 수록**
   - 🇰🇷 **한국 (현대·기아·제네시스 10종)**: 아이오닉 9, 더 뉴 아이오닉 5, 더 뉴 아이오닉 6, 캐스퍼 일렉트릭(인스터) / 기아 EV3, EV4, EV5, 더 뉴 EV6, EV9 / 제네시스 더 뉴 GV60
   - 🇩🇪 **독일 (폭스바겐·BMW·벤츠·아우디·포르쉐 15종)**: 폭스바겐 ID.4, ID.5, ID.7 / BMW 신형 iX3(노이어 클라쎄), i5, i4, iX1 / 벤츠 전기 CLA, 전기 GLC, GLE EQ(EQE SUV) / 아우디 Q6 e-트론, A6 e-트론, Q4 e-트론 / 포르쉐 마칸 일렉트릭, 더 뉴 타이칸
   - 🇺🇸 **미국 (테슬라·쉐보레·캐딜락·포드·리비안·루시드 9종)**: 테슬라 모델 Y 주니퍼, 모델 3 하이랜드, 사이버트럭 / 쉐보레 이쿼녹스 EV / 캐딜락 리릭 / 포드 머스탱 마하-E, F-150 라이트닝 / 리비안 R1S Gen 2 / 루시드 그래비티
   - 🇨🇳 **중국 (BYD·샤오미·지리·지커·샤오펑 9종)**: BYD 시걸(돌핀 서프), 아토 3, 씰(Seal), 씨라이언 7(Sealion 7) / 샤오미 SU7 Max, YU7 Max / 지리 싱위안 / 지커(Zeekr) 7X / 샤오펑(XPeng) G6
   - 🇯🇵 **일본 (토요타·혼다·닛산·렉서스·스바루 5종)**: 토요타 신형 bZ4X, 혼다 프롤로그(Prologue), 닛산 아리야(Ariya), 렉서스 RZ 450e, 스바루 솔테라(Solterra)

2. **실차 이미지 & 제조사 공식 홈페이지 연결**
   - 48개 전 차종에 Wikimedia Commons 실차 사진(`loading="lazy"`)과 오프라인/로드 실패 대비 차종별 벡터 실루엣 폴백(SVG)을 적용했습니다.
   - 각 차량 카드, 전체 스펙 일람표, 1:1 비교 모달에서 한국어/영어 언어 설정에 맞춘 **제조사 공식 홈페이지(`🌐 공식 홈페이지 ↗`)**로 즉시 이동할 수 있습니다.

3. **다중 국가 복수 선택 & 모바일 반응형 UI**
   - **다중 국가 필터 & `🚫 중국 제외` 프리셋**: 여러 국가 버튼을 동시에 선택하거나 원클릭으로 중국 제조사를 제외한 39종(KR·DE·US·JP)만 비교할 수 있습니다.
   - **모바일 최적화**: 스마트폰 화면에서도 헤더, 2x2 KPI 요약, 검색/정렬, 3열 뷰 전환 탭, 하단 고정 비교 독(Dock)이 가로 잘림 없이 깔끔하게 동작합니다.

## 🚀 빌드 및 배포

- 스타일시트 재빌드: `npm run build` (`src/input.css` → `assets/css/main.css`)
- GitHub Actions 워크플로우([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml))를 통해 `main` 브랜치 푸시 시 자동으로 배포됩니다.
